# Pizza Bros Cinematic Production Blueprint

## Experience

The website is one continuous 3D pizza story. The Pizza Bros chef mascot owns the hero and follows the visitor's cursor. Scrolling transfers focus from the mascot to the pizza. That same pizza moves through sauce, cheese, toppings, oven heat, flavor selection, customization and final boxing.

## Chapters

1. Hero Handoff: mascot reacts to the pointer and presents the pizza.
2. Sauce Flight: sauce rings spiral over the persistent pizza.
3. Cheese Rain: ingredients fall through layered 3D depth.
4. Topping Orbit: toppings orbit and close around the pizza.
5. Oven Climax: the oven moves from distant architecture to full frame heat.
6. Flavor Selector: the live 3D pizza changes between four recipes.
7. Build Your Own: topping controls change the live pizza.
8. Order Resolution: the pizza lowers into the branded box beside quantity and order controls.

## Runtime

The final delivery is intentionally self contained. It uses a custom WebGL2 renderer and procedural high segment 3D geometry. There are no external libraries, model URLs, CDNs, APIs or runtime asset requests. The mascot, pizza, toppings, oven, box, lighting, materials and motion are all generated by the local source in `src/main.js`.

## Responsive Behavior

Desktop uses the asymmetric mascot hero and large lateral camera moves. Mobile centers the focal object, shortens the camera path and disables heavy pointer movement. The document keeps semantic HTML controls above the fixed canvas.

## Accessibility

Flavor, topping, quantity and order controls are real buttons. Navigation uses anchors. Focus states are visible. Reduced motion mode shortens scroll interpolation and anchor motion.

## Performance

WebGL uses shared geometry buffers, lightweight materials, one shader program and a capped device pixel ratio. The scene has no external asset loading. Geometry is reused across toppings, bricks and character parts.

## Security

The site is static. It does not use eval, Function constructors, external scripts, client secrets, user supplied HTML, cookies, analytics or network requests.
