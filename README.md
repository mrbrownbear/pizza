# Pizza Bros — Serious Cinematic Edition

A dark, editorial Three.js experience built around one connected product journey: Samurai Pizza Cat → pizza handoff → sauce → toppings → oven → signatures → customizer → box.

## Run

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
```

## Local assets

Runtime assets are local. The site does not fetch the mascot or audio from the live web. Food presentation is carried by the 3D scene and vector UI, not raster section imagery.
