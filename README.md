# Pizza Bros Cinematic 3D Website

Complete self contained cinematic pizza website.

## Included

* Fully procedural WebGL 3D mascot, pizza, toppings, oven and pizza box
* Cursor reactive mascot in the hero
* Persistent pizza handoff that follows the full scroll story
* Sauce, cheese and topping assembly sequence
* Full screen oven climax
* Interactive flavor selector that changes the live 3D pizza
* Build your own topping controls that update the live pizza
* Quantity and order interaction
* Responsive mobile layout and reduced motion support
* No external runtime assets, APIs, libraries or CDNs

## Run

Open `index.html` directly in a modern browser, or serve the folder locally:

```bash
python -m http.server 5173
```

Then open `http://localhost:5173`.

## Deploy

The project is static and Vercel compatible. Deploy the folder as is with no build command.
"# pizza"
